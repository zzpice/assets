# 游戏封面

个人精选图库，默认每部作品只收录一张清晰、构图完整、可确认身份的正式发行封面。按画质、构图和来源选择，不以首版、首发平台或地区为硬性条件；后续正式版本可以作为作品的展示封面，但不能拿另一作品或合集封面替代该作品。

## 组织与资料

```text
game-covers/<系列>/<作品>.jpg
game-covers/<系列>/extras/<作品>/<名称>.jpg  # 少数额外收藏
```

也支持 PNG。目录与文件名使用小写英文、数字和短横线。默认图片直接放在系列目录内，没有 `main`、`alternate` 或 `edition` 字段；确有收藏价值的额外封面才放入 `extras`，不预建多版本目录。

资料只在 `catalog.json` 维护：`gameSeries` 登记 `id` 与系列名称 `title`；`games` 登记 `series`、`id`、作品名称 `title` 与 `firstReleaseYear`。首发年属于登记作品本身，与选用封面的平台或发行时间无关。重制或合集若作为独立作品收藏，单独登记即可。

每作可登记 `synopsis: { "text": "简短的无剧透剧情介绍", "source": "https://官方介绍页面" }`，在封面卡片中折叠显示「剧情简介」与依据链接。同一作品的额外封面共用简介，不在图片记录中重复保存。简介按开发商、发行商或官方商店的介绍概括开场设定，不复制长篇文案、不揭示凶手或结局；合宿等外传只介绍其实际设定，不编造主线剧情。简介依据与图片 `source` 分开，不能把游戏介绍页当作封面再分发许可。

每张图片只需 `path` 和一个出处页面或原图链接 `source`。平台、地区或简短版本说明仅在识别图片时有用才填写：

```json
{
  "path": "game-covers/zero-escape/virtues-last-reward.jpg",
  "source": "https://images.launchbox-app.com/6cd07fb7-2431-4a5a-957d-671c821ef33c.jpg",
  "cover": { "platform": "PlayStation Vita", "region": "North America" }
}
```

整个 `cover` 对象可省略；需要时可补充 `cover.version`。标题、系列与作品归属、实际宽高、大小、内容标识和预览自动生成，图片记录不保留 `note`。替换封面时同步核对并更新 `source` 及可选版本说明。无需在 README 另抄收录清单或人工填写处理记录。

## 来源与图片

- 优先开发商、发行商或游戏平台；可靠游戏数据库、历史媒体库及身份明确的封面扫描同样可以收录。可靠资料站有明显更好的素材时，可以优先使用。
- 代表封面的语言优先级：在封面真实性、构图完整度和实际画质相近时，优先选择正式发行的英文版封面；没有合适的英文版，或英文版实际画质明显更差时，使用日文版或其他正式发行版本。语言优先级不能压过实际画质和构图质量，不为统一英文换用明显更模糊、压缩更严重或裁切更差的图片。没有正式英文版的作品正常使用其他正式版本；`extras` 中的额外收藏不强制统一语言。
- 人工检查作品、平台和版本是否对应；不使用搜索缩略图、不明转载、水印图、同人图、玩家自制英文版、二次修改 Logo、非正式翻译封面、AI 重绘或身份不明的封面。正式数字发行的商店封面也可选择，但不能把自制盒装封面当作正式版本。低分辨率不是硬性拒绝理由，但仍优先寻找实际细节更清楚的图片，不以像素数或放大后的尺寸判断画质。
- 保留下载源文件的尺寸、比例和构图，不强制 1000×1500，不添加白边、拉伸或 AI 重构。网页使用自动生成的等比小预览，在 2:3 容器中 `object-fit: contain` 完整显示；空余部分以同图模糊背景装饰。装饰只用于网页，下载仍是源文件，大图预览也保留原始比例。

图库首页每个系列一行，每作只显示选定封面；点击系列进入 `#series=<系列>`，按作品首发年排列。少数额外收藏在对应作品下折叠显示，搜索仍可找到。没有作品详情页或额外路由框架。

新增或替换后运行 `python3 scripts/update_catalog.py`，提交图片与生成文件；提交前运行 `python3 scripts/update_catalog.py --check`。工具检查路径、作品登记、首发年、来源链接、可读取的真实 JPEG/PNG，以及每作默认图片唯一、额外收藏有对应作品图片。来源可信度、实际画质、构图和语言优先级由人工判断：比较下载原图的细节与压缩痕迹，并以相同展示大小核对完整构图，确认英文版是该作品的正式发行封面后再决定是否替换。工具不按地区推断语言，不强制英文、官方域名、平台、地区、分辨率或颜色模式，也不增加语言字段。详见[维护说明](../scripts/README.md)。
