# 图片目录维护

## 上传约定

- 先阅读根目录 README 和现有目录，确认用途为壁纸、头像、图标、银行卡面或其他资源；内容分类优先复用已有目录，有实际需要时再新增。
- 壁纸的内容分类与适用设备分开处理；头像不按横竖方向分类，也不只凭方形尺寸认定为头像。
- 默认保留原图尺寸、格式和画面，不擅自裁剪、放大或重新压缩。目录尺寸以工具读取的实际显示尺寸为准；放大处理需在 `note` 中注明来源尺寸和处理方式。
- 文件名描述主体或场景，使用小写英文、数字和短横线。上传前检查重复图片及同名文件，只有明确替换时才覆盖。
- 新图生成目录后补充易辨识的 `title`：壁纸与头像使用中文描述，图标遵循所属目录的品牌命名约定。壁纸检查 `device`，无法判断时保留 `unknown`。新增第三方图标还须更新 `icons/SOURCES.md`、分类数量和相应许可文件。
- 图标按[用途分类](../icons/README.md)归档，服务图标与代理组功能图标分开。新分类会自动追加到已有分类之后；需要调整默认顺序或中文名称时更新 `app/site.js` 的分类清单和图标说明。
- 银行卡面先按[卡面规则](../bank-cards/README.md)登记银行及来源，再运行工具。原版必须提供来源集合 `collection`、允许的钱包 `wallet`、原文件 HTTPS 地址 `url`、匹配的 `sha256`、正整数 `cardId` 和 `assetId`、`YYYY-MM-DD` 获取日期 `retrieved`；修改版必须用 `derivedFrom` 关联原版。地区和银行顺序由 `catalog.json` 的 `cardBanks` 清单维护。

## 更新与检查

使用 Python 3.10 或更新版本，安装一次依赖：

```sh
python3 -m pip install -r scripts/requirements.txt
```

添加、替换或删除图片后运行：

```sh
python3 scripts/update_catalog.py
```

把原图和工具生成的变化一起提交，包括 `catalog.json`、`app/previews/`、`index.html` 和 `sw.js`。工具读取实际尺寸、从目录读取风格分类、更新文件大小和内容标识、生成小型 WebP 预览、移除不再使用的预览，始终保留原图。壁纸和头像目录尺寸写错时会停止并指出正确尺寸。

`icons/` 下的图标须为 512×512 PNG、RGBA，r=115 圆角外侧完全透明。工具会检查并拒绝不合规文件，不自动修图，也不生成重复预览。

修改界面脚本、样式或离线逻辑后也运行同一命令，并提交 `index.html` 和 `sw.js` 的变化。工具会生成界面、目录及必需资源的内容校验值，完整校验和缓存成功后才安装新版本；后台更新在关闭所有图库页面、重新打开后使用。打开期间继续使用同一版本的界面与目录，不读取实时 GitHub 文件树。

离线缩略图最多保留 32 张，图标预览最多保留 64 个；图标按原文件的内容标识缓存，替换图标后不会复用旧版本。更新界面时保留仍在目录内的预览缓存；新版本优先预缓存壁纸和头像，下载原图仍需联网。

展示标题和处理说明可在 `catalog.json` 中编辑，`title` 和 `note` 必须为字符串，图片路径不能重复。手动修改后再次运行更新命令，让缓存版本同步。替换原图后保留标题，旧的处理说明会清除，请按新图补充。GIF 的列表预览显示首帧，下载保留动画；SVG 使用原矢量图预览。

金融图标的 `title` 按品牌总部所在地的常用名称填写，中国大陆银行使用中文，国际品牌保留总部常用名称，例如 DBS、OCBC、UOB。仅维护一个展示标题，不追加中英文对照、地区适用说明或搜索别名；搜索直接匹配现有标题和文件路径，不另建总部或语言字段。

适用设备会按实际尺寸和比例初步分类为手机、电脑、平板；无法明确区分的尺寸（例如 1080×1920）保留为「待分类」。可在 `catalog.json` 中用 `device` 修正：`phone`、`desktop`、`tablet`、`unknown`，手动分类优先。只有手机竖屏壁纸提供锁屏效果，其他图片使用普通预览。

上传前运行 `python3 scripts/update_catalog.py --check`，确认检查通过，并将原图与生成文件一起提交。此命令只检查、不写文件；它检查路径、尺寸、图标标准及生成文件是否同步，内容分类与适用设备仍需人工判断。
