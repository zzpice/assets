# assets

`zzpice` 的个人静态资源仓库，通过 GitHub Pages 提供固定外链。

## Avatar

<img src="https://zzpice.github.io/assets/avatar.png" alt="avatar" width="256">

**推荐地址（GitHub Pages）**

```text
https://zzpice.github.io/assets/avatar.png
```

**备用地址（GitHub Raw）**

```text
https://raw.githubusercontent.com/zzpice/assets/main/avatar.png
```

**Markdown**

```markdown
![avatar](https://zzpice.github.io/assets/avatar.png)
```

## 使用规则

以后直接把图片放进仓库即可，外链规则固定为：

```text
https://zzpice.github.io/assets/<文件路径>
```

例如：

```text
backgrounds/wallpaper.png
→ https://zzpice.github.io/assets/backgrounds/wallpaper.png
```

建议按用途使用 `avatars/`、`backgrounds/`、`logos/`、`screenshots/` 等目录；常用主头像继续固定为根目录的 `avatar.png`。
