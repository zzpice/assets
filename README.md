# 图片资源库

个人使用的精选静态资源库，收录壁纸、头像、图标、银行卡面、游戏封面与其他常用图片，不追求全面覆盖。

[浏览资源](https://zzpice.github.io/assets/) · [归档规则](#归档) · [维护说明](scripts/README.md) · [ZZP · 所有项目](https://zzp.moe/)

## 使用

- 在网站中筛选、预览、下载原图，或复制资源外链；点击顶部「图片资源库」返回默认首页。
- 手机可点「添加到桌面」查看安装指引；离线可浏览已缓存的预览和图标，下载原图需联网。
- 收藏保存在当前浏览器。
- 全部种类按分类分组；壁纸先分设备，再分种类，银行卡面先分地区，再分银行。游戏封面每作默认一图，点击系列进入按首发年排列的系列页；每张封面可展开无剧透的剧情简介及依据链接，少数额外收藏在系列页展开。其他资源的尺寸和名称排序用于组内图片。
- 壁纸的适用设备可直接选择，不必展开筛选；设备与内容分类独立，保留人工确认的归属，不把横竖比例直接等同于用途。筛选只提供当前上级条件下存在的选项，切换设备、分类或地区后自动清除不兼容的下级条件；只有一个取值且未选中的控件不显示，组内排序没有实际差异时也不显示。
- 搜索限定当前资源用途（游戏系列页限定当前系列），可用空格组合关键词，匹配现有名称、分类、文件路径及已登记资料。搜索、筛选、排序与收藏模式会保存在当前网址中，支持刷新和浏览器前进后退；点击已选中的用途保留条件。预览关闭后返回原列表，游戏系列导航保留搜索词。收藏内容仍只保存在当前浏览器。
- 图片预览和人物资料关闭后保留原列表的展开内容、浏览位置和键盘焦点；人物详情支持浏览器返回／前进，直接打开人物分享链接后也可返回对应列表。长详情滚动时，顶部关闭按钮保持可见；各类原图下载在离线时均提示联网。

外链格式：`https://zzpice.github.io/assets/<文件路径>`。

## 归档

按用途、内容种类和实际像素尺寸组织：

```text
wallpapers/<种类>/<宽>x<高>/<名称>.<格式>
avatars/<种类>/<宽>x<高>/<名称>.<格式>
icons/<用途分类>/<名称>.png
bank-cards/<originals或custom>/<地区>/<银行>/<名称>.<格式>
game-covers/<系列>/<作品>.jpg
<其他用途>/<名称>.<格式>
```

- 种类按内容选择，如 `anime`（动漫）、`landscape`（风景），按需新增；同图不同尺寸分别归档。
- 名称使用小写英文、数字和短横线，无需重复种类和尺寸；同名时先检查内容，仅在明确替换时覆盖，保留不同图片或版本时另取名称或加 `-v2`、`-v3`。
- 图标统一为 512×512 PNG、RGBA，r=115 圆角外侧完全透明。详见[图标分类、来源与许可](icons/README.md)。
- 银行卡面按地区和银行归档，原版与修改版分开；原始文件不覆盖。详见[卡面目录与来源规则](bank-cards/README.md)。
- 游戏封面保留源图尺寸与比例，网页统一用 2:3 容器完整展示。优先选择清晰、构图完整且来源可信的正式封面，不限首版；真实性、构图和实际画质相近时优先正式英文版，画质或构图明显更差时保留其他正式版本。详见[游戏封面收录与维护](game-covers/README.md)。

## 维护

按[维护任务索引](scripts/README.md#按任务查规则)查找各类资源的收录规则、资料编辑位置和操作步骤。

新增、替换或删除资源，以及修改展示资料或网站界面后，按[维护说明](scripts/README.md#更新与检查)更新目录、预览和缓存版本。`catalog.json` 同时包含人工维护资料和生成内容，编辑位置见任务索引；资源分类从目录读取，放大图注明来源尺寸。`app/` 存放网站界面与预览资源。

## 版权与许可

本仓库包含不同来源的图片、卡面和品牌资源，不提供统一的仓库级许可。第三方资源的版权、商标及其他权利归原权利人所有；已知来源与许可信息见各分类说明及来源文件。[壁纸与头像来源记录](wallpapers/SOURCES.md)保存维护者对六张 GPT 原创生成图片的说明；人物图片的具体许可见登记数据及网页详情。

## 项目体系

属于 [ZZP 工具与资源](https://zzp.moe/)。共同的[设计与仓库规范](https://github.com/zzpice/zzp-home/blob/main/docs/design.md)由入口仓库维护；使用步骤、生成产物和验证方式仍以本仓库为准。
