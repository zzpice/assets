# 静态资源库

个人壁纸、头像、图标与其他图片资源，支持筛选、下载和复制外链。

[浏览资源](https://zzpice.github.io/assets/)

## 归档规则

以下是通用路径模板，目录按用途、种类和实际尺寸组织：

```text
wallpapers/
└── <种类>/
    └── <宽>x<高>/
        └── <名称>.<格式>
avatars/
└── <种类>/
    └── <宽>x<高>/
        └── <名称>.<格式>
<其他用途>/
└── <名称>.<格式>
```

- 壁纸种类按内容选择，例如 `anime`（动漫）、`landscape`（风景）、`minimal`（极简），可按需新增。
- 尺寸填写实际像素，如 `1920x1080`、`1440x3120`；同图不同尺寸放入各自目录。
- 名称使用小写英文、数字和短横线，无需重复目录中的种类和尺寸。
- 替换图片直接覆盖；需要同时保留多个版本时，名称加 `-v2`、`-v3`。
- 头像也按内容种类和实际尺寸归档，例如 `anime`（动漫）、`people`（真人）、`animals`（动物）、`pixel`（像素）；图标、标识等按用途建目录。
- 精选图标放在 `icons/brands/<名称>.png` 和 `icons/general/<名称>.svg`，每项只保留一个版本；[收录清单、来源与许可](icons/README.md)。

## 使用

提交图片后，首页自动显示。`catalog.json` 可选，用于中文标题、分类、处理说明和 `thumbnail` 预览图；放大图注明来源尺寸。`app/` 存放网站界面与预览资源，不显示在图库中。

手机上可点「添加到桌面」查看安装指引。添加后独立打开，离线可浏览已缓存的预览，原图下载需联网。点心形收藏图片，收藏保存在当前浏览器。

壁纸按适用设备、画面风格和分辨率筛选；「全部设备」按设备分组展示，预览在当前分组内切换。头像按画面风格和分辨率筛选。手机壁纸可选锁屏效果，头像可切换圆形效果，下载始终保留原图。预览支持分享，返回键关闭预览。

新增或替换图片时，可用[整理工具](scripts/README.md)自动更新设备分类、目录、预览并检查实际尺寸。

图片外链：`https://zzpice.github.io/assets/<文件路径>`。
