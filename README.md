# 静态资源库

个人使用的精选静态资源库，收录壁纸、头像、图标、银行卡面、游戏封面、女优人物图库与其他常用图片，不追求全面覆盖。

[浏览资源](https://zzpice.github.io/assets/)

## 使用

- 在网站中筛选、预览、下载原图，或复制资源外链。
- 手机可点「添加到桌面」查看安装指引；离线可浏览已缓存的预览和图标，下载原图需联网。
- 收藏保存在当前浏览器。
- 全部种类按分类分组；壁纸先分设备，再分种类，银行卡面先分地区，再分银行。游戏封面每作默认一图，点击系列进入按首发年排列的系列页；少数额外收藏在系列页展开。其他资源的尺寸和名称排序用于组内图片。

外链格式：`https://zzpice.github.io/assets/<文件路径>`。

[女优图库](https://zzpice.github.io/assets/#actresses=annual)提供年度榜单、名人堂、全部女优三个入口，共用人物资料和每人一张头像。年度采用 2023 年起的 FANZA 月额 DVD 租赁官方 TOP 100；名人堂为项目精选，不设排名。搜索支持已记录姓名、别名与罗马字，每页最多 48 人；详情名次与次数只统计已收录年份。

## 归档

按用途、内容种类和实际像素尺寸组织：

```text
wallpapers/<种类>/<宽>x<高>/<名称>.<格式>
avatars/<种类>/<宽>x<高>/<名称>.<格式>
icons/<用途分类>/<名称>.png
bank-cards/<originals或custom>/<地区>/<银行>/<名称>.<格式>
game-covers/<系列>/<作品>.jpg
actresses/portraits/<稳定人物ID>.<源格式>
<其他用途>/<名称>.<格式>
```

- 种类按内容选择，如 `anime`（动漫）、`landscape`（风景），按需新增；同图不同尺寸分别归档。
- 名称使用小写英文、数字和短横线，无需重复种类和尺寸；同名时先检查内容，仅在明确替换时覆盖，保留不同图片或版本时另取名称或加 `-v2`、`-v3`。
- 图标统一为 512×512 PNG、RGBA，r=115 圆角外侧完全透明。详见[图标分类、来源与许可](icons/README.md)。
- 银行卡面按地区和银行归档，原版与修改版分开；原始文件不覆盖。详见[卡面目录与来源规则](bank-cards/README.md)。
- 游戏封面保留源图尺寸与比例，网页统一用 2:3 容器完整展示。优先选择清晰、构图完整且来源可信的正式封面，不限首版；真实性、构图和实际画质相近时优先正式英文版，画质或构图明显更差时保留其他正式版本。详见[游戏封面收录与维护](game-covers/README.md)。

## 维护

女优人物资料在 `actresses/data.json` 和年度来源快照维护，生成到展示目录；头像保留源图，以 3:4 容器完整展示。详见[人物、榜单、来源与更新规则](actresses/README.md)。

新增、替换或删除资源后，按[维护说明](scripts/README.md)更新目录和预览。标题、分类、游戏资料、来源及必要的短说明由 `catalog.json` 管理；放大图注明来源尺寸。`app/` 存放网站界面与预览资源。
