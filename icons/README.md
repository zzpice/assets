# 精选图标

24 个静态图标，用于个人导航、文档、网页和服务分组。品牌图标采用 512×512 PNG，通用图标保留可缩放的 SVG；每项只有一个文件。

路径为 `icons/brands/<名称>.png`、`icons/general/<名称>.svg`。名称使用小写英文和短横线，不按品牌母公司嵌套，不建立尺寸或明暗变体。

## 取舍与维护

服务图标覆盖 AI、开发、影音、沟通、存储与笔记；通用图标覆盖网络、安全、搜索、下载、文件、链接、设置与收藏。

暂不收录国旗、冷门地区服务、品牌全家桶、短期活动标识以及同图多尺寸/明暗变体。仅在实际需要时手动添加或替换；不自动同步上游，不引入图标字体、安装包、订阅配置或专用构建流程。

使用直链，例如 `https://zzpice.github.io/assets/icons/brands/github.png`；网站「图标」页支持预览、下载和复制链接。
